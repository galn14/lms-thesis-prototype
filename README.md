# LMS Thesis Prototype

Prototype Learning Management System untuk demonstrasi fitur Automated Grading dan Plagiarism Detection menggunakan data sintetis. Repository ini disiapkan untuk deployment demonstrasi dan tidak memuat data siswa asli maupun kredensial layanan eksternal.

## Attribution

Prototype ini dikembangkan dari LMS SMA Katolik St. Louis 2 Surabaya yang dikerjakan pada repository `Josedio30/LMS_StLouis2`. Nama dan logo sekolah dipertahankan untuk kebutuhan atribusi dan konteks akademik. Penambahan fitur penelitian dan penyusunan prototype dilakukan oleh Galeno Areliano.

Repository ini tidak menambahkan lisensi baru. Hak atas LMS dasar, nama, logo, dan materi terkait tetap berada pada pemiliknya masing-masing.

## Status

- Seluruh akun, kelas, tugas, jawaban, nilai, dan hasil pemeriksaan pada deployment prototype bersifat sintetis.
- Pemrosesan eksternal berbayar dinonaktifkan pada deployment prototype.
- Petunjuk setup Neon, reset data, akun demo, dan deployment Vercel akan ditambahkan pada tahap konfigurasi deployment.
